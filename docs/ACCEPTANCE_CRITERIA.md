# ACCEPTANCE CRITERIA — Criterios de Aceptación de Producto

> **WHO Animal v1**  
> `STATUS: FOUNDATION / DRAFT`

Estos criterios permitirán al Project Manager (PM) y al Product Owner verificar la fidelidad conceptual de las futuras implementaciones.

---

## 1. Campamento Base (Home / Explorer)
* [ ] La Home transmite una atmósfera natural y serena, adaptada sutilmente a la hora del día.
* [ ] La acción primaria **DESCUBRIR** es visible y comprensible al primer segundo sin necesidad de explicaciones.
* [ ] La pantalla carece por completo de barras de HP/MP, niveles numéricos de jugador, balances de monedas o botones de tienda.
* [ ] La mochila de colección es accesible con un único gesto o toque evidente.

## 2. Visor de Captura (Capture)
* [ ] El visor de cámara no contiene retículas militares, miras tácticas ni artificios tecnológicos futuristas.
* [ ] El disparador reacciona de forma inmediata y fluida.
* [ ] Se muestran pautas sutiles de observación responsable y silenciosa.

## 3. Identificación y Honestidad Científica (Identification)
* [ ] La identificación no se comunica como una verdad absoluta o dogma infalible.
* [ ] Se presenta el grado cualitativo de confianza y alternativas si la toma es ambigua.
* [ ] Ante una foto no concluyente, la app no inventa una especie; ofrece clasificarla como pendiente o reintentar sin frustración.
* [ ] Se mantiene la separación estricta entre `Observation`, `IdentificationResult` y `Decision`.

## 4. Momento de Descubrimiento (Discovery)
* [ ] Existe una pausa de revelación previa que aporta peso emocional al hallazgo.
* [ ] Se presenta de forma digna y destacada el nombre común y el nombre binomial en cursiva.
* [ ] La transición hacia la generación de la carta es natural y fluida.

## 5. La Carta como Artefacto (Card)
* [ ] La carta incorpora la fotografía real tomada por el usuario durante la observación.
* [ ] Presenta los tres pilares delimitados: Hechos Científicos, Datos de la Experiencia y Lore Lúdico.
* [ ] El bloque de Lore lleva de forma obligatoria y visible la advertencia de ficción narrativa lúdica.
* [ ] Se incluyen avisos de precaución objetivos en especies que presenten defensas naturales, sin alarmismos.

## 6. Mochila / Colección (Collection)
* [ ] La colección se siente como una bitácora o cuaderno de expedición y no como una tabla de administración de base de datos.
* [ ] Cada carta puede abrirse e inspeccionarse individualmente.
* [ ] El progreso se percibe como la acumulación de encuentros personales con la naturaleza.

## 7. Principio 100% Pet Friendly
* [ ] No existen palabras de dominación, combate ni captura violenta en ningún texto del sistema.
* [ ] No se incentivan conductas de riesgo, persecución ni manipulación de animales silvestres.
* [ ] Las especies vulnerables omiten coordenadas exactas de localización para prevenir furtivismo.
