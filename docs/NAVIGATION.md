## 1. Estructura Conceptual del Recorrido

La navegación de Who Animal v1 responde a un flujo orgánico y centrado en la exploración:

```text
[ HOME / CAMPAMENTO BASE ]
       │
       ├──► [ CAPTURA / VISOR DE CAMPO ]
       │          │
       │          ▼
       │    [ IDENTIFICACIÓN ]
       │          │
       │          ▼
       │    [ DESCUBRIMIENTO ]
       │          │
       │          ▼
       │     [ DETALLE DE CARTA OBTENIDA ]
       │
       └──► [ MOCHILA / COLECCIÓN DE CRIATURAS ]
                  │
                  ▼
            [ DETALLE / INSPECCIÓN DE CARTA ]
```

---

## 2. Principios de Navegación

1. **Inmersión sin distracciones:** Transiciones fluidas y orgánicas que no rompen la sensación de estar en una expedición al aire libre.
2. **Jerarquía clara:** El botón de acción principal en Home siempre orienta hacia el descubrimiento.
3. **Acceso directo a la Colección:** La mochila del explorador está siempre disponible para contemplar las piezas obtenidas.
4. **Aclaración:** Este mapa representa la dirección conceptual. La implementación técnica de navegación concreta (Compose Destinations, Jetpack Navigation, etc.) será abordada y formalizada en fases posteriores.
