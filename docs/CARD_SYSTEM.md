# CARD SYSTEM — El Sistema de Cartas como Artefacto

> **WHO Animal v1**  
> `STATUS: FOUNDATION / DRAFT`

---

## 1. La Carta como Pieza de Identidad

La **Card** es el artefacto coleccionable central de Who Animal v1. No es una simple fila en una base de datos ni una tarjeta genérica de interfaz; es la materialización tangible de un encuentro real entre el usuario y la naturaleza.

Posee identidad propia, acabado visual cuidado y transmite valor de permanencia.

---

## 2. Separación Estricta de los Tres Pilares

Cada carta articula tres dimensiones de contenido que jamás deben mezclarse ni confundirse:

```text
┌─────────────────────────────────────────────────────────┐
│                    CARTA DE CRIATURA                    │
├─────────────────────────┬───────────────────────────────┤
│ 1. INFORMACIÓN          │ Factual, taxonómica,          │
│    CIENTÍFICA           │ contrastable, educativa.      │
├─────────────────────────┼───────────────────────────────┤
│ 2. EXPERIENCIA          │ Visual, táctil, arte,         │
│                         │ acabados, coleccionismo.      │
├─────────────────────────┼───────────────────────────────┤
│ 3. LORE                 │ Narrativa fantástica, estilo   │
│                         │ cuaderno de naturalista.      │
│                         │ *Siempre con aviso explícito* │
└─────────────────────────┴───────────────────────────────┘
```

1. **Información Científica:** Datos zoológicos fidedignos, nombres científicos, dieta, hábitat y estado de conservación real.
2. **Experiencia:** Composición visual, sensación táctil, marco, relieve e impacto estético.
3. **Lore:** Narrativa sutil que aporta personalidad lúdica y mitología sin falsear la biología. **Regla inquebrantable:** Nunca presentar Lore como información científica; debe portar su propio contenedor y advertencia de ficción.

---

## 3. Avisos de Campo Responsables

Los avisos de ⚠️ *Precaución* o ⚠️ *Peligro* deben ser rigurosos, objetivos y educativos (p. ej., distanciamiento seguro, respeto a nidos o crías), evitando cualquier tipo de sensacionalismo o temor infundado hacia la fauna.
